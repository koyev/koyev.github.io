# markojevic.com

Personal website and portfolio. Static: markdown and Nunjucks in, HTML in `dist/`, no
framework, no client-side router, no build step you have to think about.

Scaffolded with [`create-poops`](https://github.com/stamat/create-poops) from the [shitstorm](https://github.com/stamat/shitstorm) template and built by [poops](https://github.com/stamat/poops). Bundling, templating, `sitemap.xml`, `robots.txt` and `llms.txt` all come out of the one `poops.json`.
